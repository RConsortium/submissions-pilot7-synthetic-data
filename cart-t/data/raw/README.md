# Raw Datasets

Generated by `program/raw/load_xml.R` from `car-t-openclinica.xml` (OpenClinica
ODM export). Each `.rds` is a tibble with one row per `ItemData` (one CRF item
value); shared columns: `subjectkey`, `studyeventoid`, `eventname`,
`formname`, `itemgroupname`, `itemoid`, `itemname`, `value`, plus form / item
group / event status fields.

## Not present in this export

The study spec mentions the following forms, but they do not appear in
`car-t-openclinica.xml`:

- ICF (eConsent) — electronic informed consent
- EQ-5D-5L Questionnaire — health-status questionnaire
- Skin Conditions Questionnaire
- Evaluator B (counterpart to Evaluator A for independent adjudication)
