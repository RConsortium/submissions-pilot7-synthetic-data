# Statistical review workbook

The full runner writes `review.html` here. Open it locally after building,
or download and extract the complete `cart-t-review` CI artifact. The file
contains its own data and scripts; it needs no server or network.

Keep the extracted `cart-t/` tree together for CSV/XPT/Define-XML links.
Search by human subject ID, native subject key or any displayed value.
Select a row for SDTM/source traceability and a column heading for its
executable derivation. The other views show YAML, review queries and audit
results. Raw clinical text is rendered as data, not executable markup.

No inferential tables, listings or figures are supplied without an approved
SAP, populations, exposure reference and endpoint definitions.
