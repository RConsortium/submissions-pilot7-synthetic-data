# ARA06_output — NCT00837434 Synthetic IPD Run

Digital-twin individual-patient data for **ARA06 / NCT00837434** — a Phase IV,
2:1 randomized trial of **etanercept vs adalimumab** (both on background
methotrexate) in rheumatoid arthritis. Generated by the
[`clinical-trial-ipd-sim`](../.claude/skills/clinical-trial-ipd-sim/SKILL.md)
g-formula causal-DAG engine (`ara06/` package).
