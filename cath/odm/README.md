# CATH ODM — synthetic IPD run manifest

Synthetic individual-patient data for **ADVN CATH 03-01** (NCT00789880), a Phase 2,
single-center (UCSD), randomized 1:1, quadruple-blind, placebo-controlled study of oral
Vitamin D3 4000 IU/day vs matching placebo over 21 days, crossed with three diagnostic
groups (Atopic Dermatitis / Non-AD healthy control / Psoriasis). Primary/secondary
endpoints are the Day-21 change from baseline in relative abundance of skin (and saliva)
antimicrobial-peptide / cytokine mRNA — CAMP and HBD-3 (primary, §7.1.1) and IL-13
(secondary) — in lesional vs non-lesional skin per group and arm. Generated by the
g-formula causal-DAG simulator; marginals calibrated to the posted ClinicalTrials.gov
results (`hasResults=true`) while the joint distribution obeys the model documented in
[`DAG.md`](DAG.md).

This ODM run uses a different simulation seed from the existing [CATH pipeline](../README.md)
and a 17-form schema.

### Out-of-tolerance cells (8 of 83)

All eight are small-subgroup artifacts, not structural failures — the DAG gates all pass:

- **Baseline categorical draws (3):** Female (0.66 vs 0.54), White (0.54 vs 0.66), Black (0.21 vs 0.11) — single-draw sampling noise on a fixed N=82 with no calibration knob that preserves the multinomial.
- **Endpoint dispersion cells (3):** CAMP AD/non-lesional/D3 sd, HBD-3 AD/lesional/placebo sd, IL-13 Psor/lesional/D3 sd — SD compressed by small per-cell n (n=4–17) and shared-frailty truncation.
- **Psoriasis placebo means (2):** CAMP Psor/lesional/placebo and Psor/non-lesional/placebo — the smallest group (n=8 placebo) pulls negative; correcting them would require moving an uncalibrated baseline-level prior that was rejected during calibration.
