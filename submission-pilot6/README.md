# submission-pilot6

This folder stages Pilot 6's SDTM inputs, ADaM derivation programs and
production ADaM references for data standardization and comparison.

- Source: https://github.com/RConsortium/submissions-pilot6-adams-tlfs
- Snapshot: `a4f85c95cfef1f6aa27795362630f8ae43210185`, the upstream `main`
  commit checked on 2026-10-24. DVC pointers pin the data, independently of
  object upload dates in S3.
- `data/sdtm/`: all 21 SDTM datasets pulled from the upstream DVC snapshot
  (ae, cm, dm, ds, ex, lb, mh, qs, relrec, sc, se, suppae, suppdm, suppds,
  supplb, sv, ta, te, ti, tv, vs). CM, LB and QS replace the earlier CDISC
  Pilot 01 copies; the other 18 already matched this source.
- `data/adam/`: all 8 production ADaM references (adadas, adae, adlbc,
  adlbh, adnpix, adsl, adtte, advs). These are imported upstream outputs,
  not outputs generated by yamaa.
- `spec/define/define-adam.xml` and `spec/pilot6-specs.xlsx`: copied from
  the same upstream commit. `spec/define/define-sdtm.xml` remains the shared
  CDISC Pilot 01 SDTM definition; Pilot 6 does not carry an SDTM define file.
- `spec/source-snapshot.json`: source commit, DVC MD5 and byte size, metadata
  source, Parquet SHA-256 and dimensions for each dataset, plus hashes of
  the two upstream specification files and all 14 retained source files.
- `spec/define/`: published Define-XML, grouped as in Pilot 3.
- `program/adam/python/`: snapshot verification and reference comparison.
- `program/adam/R/`: the shared R startup.
- `program/adam/upstream/`: the original `.Rprofile`, all 10 ADaM programs,
  and 3 dataset I/O and comparison utilities. See
  [the reproduction workflow](program/adam/README.md) for running those
  programs from staged SDTM and comparing their ADaM outputs.
- `program/adam/renv.lock`: the tested R 4.5.1 package environment, restored
  directly by CI. The [recorded results](program/adam/README.md#recorded-verification)
  show five reference matches, two reference differences, one export failure
  and two generated datasets without stored upstream references. The current
  startup script fixes the export failure, and ADLBH then matches.

## Conversion and verification

All datasets use Parquet with column labels in `yamaa:label` Arrow field
metadata. Row and column order, text (including empty strings), and nulls
are preserved. Numeric values use float64, matching the other studies;
numeric strings are parsed and whitespace-padded `NA` or empty numeric
values become null. ADaM date columns use Arrow date32. ISO datetime text
is retained as text, including the ADSL DTC variables.

Upstream `adnpix.json` contains plain row objects rather than Dataset-JSON
metadata. Its column order, labels and types come from the ADNPIX group in
the upstream ADaM Define-XML; DATE9. columns are read as ISO dates. The
other 28 files use their Dataset-JSON 1.1 metadata.

The importer checks the source files against their DVC MD5s and byte sizes,
validates dimensions, and reads back every Parquet file to verify values,
types, order and labels. Existing Parquet files that already match are kept.
This verifies the import. The upstream R reproduction workflow separately
checks generation and reference agreement; yamaa comparisons remain separate work.

## Refresh or reproduce the snapshot

The upstream S3 remote supports anonymous downloads; signup credentials
are only needed for contributor operations such as uploading data.

```bash
python -m pip install 'dvc[s3]' pyarrow PyYAML
git clone https://github.com/RConsortium/submissions-pilot6-adams-tlfs.git ../submissions-pilot6-adams-tlfs
git -C ../submissions-pilot6-adams-tlfs checkout a4f85c95cfef1f6aa27795362630f8ae43210185
(cd ../submissions-pilot6-adams-tlfs && dvc pull data/sdtm/*.dvc data/adam/*.dvc)
python .github/scripts/import_pilot6_inputs.py ../submissions-pilot6-adams-tlfs
python .github/scripts/import_pilot6_inputs.py ../submissions-pilot6-adams-tlfs --verify-only
```

Run these commands from the Pilot 7 repository root. For a later refresh,
fetch and check out upstream `main` before pulling DVC data, then review
the changed files and provenance manifest. Network policy must allow
`s3.us-east-1.amazonaws.com` as well as GitHub and package downloads.

The importer also retains `--json-dir` and `--mirror-ref` for obtaining
SDTM from a local directory or the identical Pilot 5 GitHub copy. ADaM
must still be pulled with DVC into the source checkout in these modes.
Local file reads omit `retrieved_from`; the importer records a retrieval URL
only when it downloads SDTM from the pinned GitHub mirror. All acquisition
modes still verify the source DVC size and MD5.
