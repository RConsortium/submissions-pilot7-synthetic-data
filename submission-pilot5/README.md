# submission-pilot5

R Consortium R Submission Pilot 5 (the Dataset-JSON pilot), staged for
yamaa-based SDTM-to-ADaM derivation.

- Original source:
  - [Submission package](https://github.com/RConsortium/submissions-pilot5-datasetjson/tree/main/pilot5-submission).
- Reference inputs from the submission package:
  - `data/sdtm/`: SDTM datasets converted from Dataset-JSON to Parquet.
  - `data/adam/<dataset>.parquet`: ADaM reference datasets converted from
    SAS transport (.xpt) to Parquet.
  - `spec/define/`: the SDTM and ADaM Define-XML files.
- Pilot 7 derivation assets:
  - `spec/yamaa/`: yamaa specifications for SDTM-to-ADaM derivation.
  - [program/adam/](program/adam/README.md): R and Python yamaa runners,
    the Python reference comparator, and installation instructions.
  - `program/adam/adam-compare-keys.json`: row-alignment keys for the
    repository comparison workflow.
  - `data/adam/<dataset>-yamaa.parquet`: ADaM datasets generated by yamaa.

## Review scope

The dashboard's **Start review** dialog focuses on consistency and gaps between current
`data/adam/*-yamaa.parquet` outputs and the retained
`spec/define/define-adam.xml`. It identifies both sources and reports checks
that require additional evidence as Not assessed. Reference reproduction,
YAML review and generated XML comparison remain available in the full dashboard's
**SDTM -> ADaM**, **Define-XML comparison** and **Source documents** tabs.

## Source documents

[spec/source/](spec/source/README.md) retains the original ADaM workbook,
reviewer guide, pinned provenance, and a starter inventory of rules for review.
