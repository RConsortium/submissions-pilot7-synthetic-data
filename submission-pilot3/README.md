# submission-pilot3

R Consortium R Submission Pilot 3, staged for yamaa-based SDTM-to-ADaM
derivation.

- Original sources:
  - [Development repository](https://github.com/RConsortium/submissions-pilot3-adam/tree/main/submission).
  - [eCTD submission package](https://github.com/RConsortium/submissions-pilot3-adam-to-fda).
- Reference inputs from the submission package:
  - `data/sdtm/`: SDTM datasets converted from SAS transport (.xpt) to Parquet.
  - `data/adam/<dataset>.parquet`: ADaM reference datasets converted from .xpt to Parquet.
  - `spec/define/`: the SDTM and ADaM Define-XML files.

- Pilot 7 derivation assets:
  - `data/mapping/`: ADADAS LOCF planning (`plan.csv`) and analysis-window
    definitions (`analysis_window.csv`).
    [R](program/adam/R/make_plan.R) and
    [Python](program/adam/python/make_plan.py) programs regenerate `plan.csv`.
  - `spec/yamaa/`: yamaa specifications for SDTM-to-ADaM derivation.
  - `program/adam/`: R and Python yamaa runners, the Python reference
    comparator, and R and Python planning generators.
  - `data/adam/<dataset>-yamaa.parquet`: ADaM datasets generated by yamaa.

## Source documents

[spec/source/](spec/source/README.md) retains the original ADaM workbook,
reviewer guide, pinned provenance, and a starter inventory of rules for review.
