# RAVE (NCT00104299 / ITN021AI) — synthetic IPD run

Causal-DAG, g-formula simulation of individual patient data for the RAVE trial
(rituximab vs. cyclophosphamide→azathioprine for remission induction in ANCA-associated
vasculitis). CRFs reproduce the published marginal statistics **and** follow an explicit,
literature-grounded causal DAG. Generated by the `clinical-trial-ipd-sim` skill.

### DAG gates (causal identifiability — all must pass)
✅ AE↔lab linkage (WBC at leukopenia AE 2.x ≪ ~6 overall) · ✅ arm→myelosuppression mediation
(CYC leukopenia ≫ RTX) · ✅ within-patient GI AE correlation (shared frailty) · ✅ primary
endpoint = trajectory (agreement 1.0) · ✅ stratifier→outcome (PR3 flare ≥ MPO) · ✅ AE↔DS
traceability (each AE-discontinued patient has exactly one DRUG WITHDRAWN AE; 9 = 9).

> **Note on n=197 vs. expectation.** At trial size the arm effect is noisy — RAVE's own primary
> difference was 10.6% with 95.1% CI [−3.2, 24.3]. Per-seed scatter of the simulated arm gap
> matches that sampling distribution; the calibration is validated at N=5000 (in expectation).
