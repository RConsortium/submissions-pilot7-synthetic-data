# cdiscpilot01

CDISC SDTM/ADaM Pilot Project, staged for yamaa-based SDTM-to-ADaM derivation.

- Original source:
  - [Submission package](https://github.com/cdisc-org/sdtm-adam-pilot-project/tree/master/updated-pilot-submission-package/900172/m5/datasets/cdiscpilot01).
- Reference inputs from the submission package:
  - `data/sdtm/`: SDTM datasets converted from SAS transport (.xpt) to Parquet.
  - `data/adam/<dataset>.parquet`: ADaM reference datasets in Parquet.
  - `spec/define/`: the SDTM and ADaM Define-XML files.
- Pilot 7 derivation assets:
  - `spec/yamaa/`: yamaa specifications for SDTM-to-ADaM derivation.
  - [program/adam/](program/adam/README.md): R and Python yamaa runners,
    the Python reference comparator, and installation instructions.
  - `data/adam/<dataset>-yamaa.parquet`: ADaM datasets generated by yamaa.

ADQSADAS and ADQSCIBC remain outside the active project.
