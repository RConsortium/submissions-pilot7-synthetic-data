# KN564

Status: Ongoing.

KN564 is a synthetic clinical trial study used to develop and evaluate
agentic workflows for CDISC data standardization.

The planned workflow covers EDC data extraction, SDTM mapping, ADaM
derivation, and define.xml generation for eCTD submission package preparation.

[Study files](https://github.com/RConsortium/submissions-pilot7-synthetic-data/tree/main/kn564)
