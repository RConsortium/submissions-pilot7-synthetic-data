# C4591001

**Pfizer/BioNTech**, BNT162b2 (Comirnaty). The Phase 1/2/3 trial of the RNA vaccine candidates BNT162b2 and BNT162b1: dose finding in Phase 1, then a placebo-controlled, observer-blind efficacy study in Phase 2/3; 46,636 participants were randomized. PHMPT released eight deliverables with analysis datasets. From BLA 125742: the safety and efficacy analysis (S1, cutoff 13 Mar 2021) with its supplementary datasets, the sequencing (XB) datasets (S6), and the 1-month and 6-month analyses of adolescents (S211). From EUA 27034: the interim efficacy analysis and the safety and final efficacy analysis (S1), and the resubmission for adolescents 12 to 15 (S135).

Specs: [`phmpt/c4591001`](https://github.com/RConsortium/submissions-pilot7-synthetic-data/tree/main/phmpt/c4591001) - yamaa `ac826f0` - results collected 2026-11-27 - terms: [glossary](../glossary.md)

Submitted data, programs and defines are not published here. To rerun this study from PHMPT, follow [`phmpt/reproduce.sh`](https://github.com/RConsortium/submissions-pilot7-synthetic-data/blob/main/phmpt/reproduce.sh): `sh phmpt/reproduce.sh setup`, then `sh phmpt/reproduce.sh c4591001`.

**How datasets are compared.** yamaa's output is matched to the submitted dataset row by row on the dataset's keys and compared cell by cell. In this study numbers are equal within 1e-10, strings are compared with spaces removed, and submitted cells FDA redacted to `(b)(6)` are not compared ([comparison rules](../glossary.md#comparison-rules)).

### Differences and their reasons

**Missing input** ([glossary](../glossary.md#missing-input)). The release lacks an input these values are derived from. The spec derives them as the program does; the listed cells cannot be recovered from the released data.

- **ADCM**: 12 columns are not derived; 7,985 rows derived, 19,925 submitted. *Missing:* WHO Drug dictionary (WHODRUG DDE v202003), licensed, not submitted. The 12 WHODRUG coding columns, and the one-row-per-ATC-class expansion (7,985 records to 19,925 rows), need the WHO Drug dictionary (WHODRUG DDE v202003), which is not in the submission. The other columns were not compared cell by cell: the comparison stops when the column sets differ.
- **ADMH**: 64 cells differ (`ASTDTF` 43, `AENDTF` 21). *Missing:* the MHSTDTC / MHENDTC values of these rows, redacted to (b)(6). The date-imputation flags of these rows come from MHSTDTC / MHENDTC values that are redacted to (b)(6) in the released SDTM, so whether a day or month was imputed cannot be recovered. Every other cell is reproduced.
- **ADSL**: 8,441 cells differ (`BRTHDTF` 1, `AGETR01` 11, `AGETR03` 7,966, `AGEGR1` 1, `AGEGR1N` 1, `AGEGR3` 1, `AGEGR4` 1, `AGEGR4N` 1, `AGEGR3N` 1, `AGETGR3` 219, `AGETGR3N` 219, `OBESEFL` 19). *Missing:* DM.BRTHDTC, redacted to (b)(6) for every subject. DM.BRTHDTC is redacted to (b)(6) for every subject, so ages at a date after informed consent (AGETR01, AGETR03), the groups built on them, the age-in-months BMI percentile behind OBESEFL and one subject's birth-date imputation flag cannot be recovered from the released data. Every other cell is reproduced.

**Missing input** ([glossary](../glossary.md#missing-input)). The release lacks an input these values are derived from. The spec derives them as the program does; the listed cells cannot be recovered from the released data.

- **ADSL**: 141 cells differ (`BRTHDTF` 1, `AGETR01` 6, `EOTDCDT` 1, `JPNFL` 129, `BMICAT` 2, `BMICATN` 2). *Missing:* DM.BRTHDTC and two subjects' height and BMI (redacted); the Japanese-participants list the program imports; one DS record the interim ADaM read, which the released interim DS does not carry. One subject's EOTDCDT (2020-11-04) comes from a vaccination-phase disposition event other than COMPLETED; the released interim DS has only the subject's COMPLETED record. Every other cell is reproduced.

**Defects of the submitted file** ([glossary](../glossary.md#submitted-defect)). The submitted file itself is defective or was not produced by its released program: a malformed cell, or rows the released program writes that the file lacks. The spec follows the program.

- **ADC19EF**: 530,152 rows derived, 528,996 submitted. *Defect:* the file lacks the PRCDCSAD rows its released program writes. The submitted interim file is inconsistent with its released program: yamaa writes 1,156 PRCDCSAD rows (presence of CDC-defined symptoms) that the file does not have, and every other cell matches. adc19ef-ia.sas gives FATIGUE, HEADACHE, RIHNRA and NAUSEA grp = 2 (symp_all_1; the interim ADSYMPT has 1,494 such records); symp_all_4 keeps the last record of each analysis visit and group (keepflg, grp < 20) and symp2 to symp5 keep every one; adc19ef_1 names it PARAMCD = 'PRCDCSAD' and writes it with an unconditional output, then writes the CDCONST record of the same record; adc19ef_3 keeps every record with a PARAMCD; the final step drops only PARAMCD in ("CDCONST", "ST1PD", "ST17PD", "ST2PD", "ST214PD", "ST214CD", "ST214SE", "ST1PDA", "ST17PDA", "ST2PDA", "ST214PDA") and the CDC flag columns, and the closing proc sort has no nodupkey. No macro, %include or where clause touches these rows. The CDCONST records did exist when the file was made: ST1CD ends at the first CDC onset, before ST1SE, for 109 subjects without a severe onset. The file was therefore not produced by the program text as released; nothing in the program or the data supports dropping the rows, so the spec keeps them.
