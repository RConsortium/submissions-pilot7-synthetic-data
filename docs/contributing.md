# Join the project

Pilot 7 welcomes contributions to benchmark datasets, test cases,
specifications, and reproducible evaluation of clinical tools.

- [Join the R Consortium Submissions Working Group](https://rconsortium.github.io/submissions-wg/join.html)
  to access the calendar and Slack workspace.
- Read the [Pilot 7 meeting minutes](https://github.com/RConsortium/submissions-pilot7-synthetic-data/wiki/Meeting-Minutes).
- Open an [issue](https://github.com/RConsortium/submissions-pilot7-synthetic-data/issues)
  or a [pull request](https://github.com/RConsortium/submissions-pilot7-synthetic-data/pulls).

Pilot 7 holds Friday standups three times a month and participates in the
monthly Submissions Working Group meetings with FDA staff. Use the shared
calendar for current meeting times.

For a derivation change, keep the official reference data intact, run the
study's validation command, and describe any remaining differences. For
website changes, regenerate the study pages from current validation evidence
and run the strict MkDocs build. See [running the project](running.md).
